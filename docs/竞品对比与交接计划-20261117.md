## 0. 产品定位锚点（不变）

对标 MobaXterm 的核心用户价值链：**连上主机 → 用终端 → 管文件 → 看得见主机状态**。
与竞品的差异化叙事：本地优先（密码不落盘、数据不出机器）+ 审批/审计安全链路——这是 MobaXterm/FinalShell 都没有的信任故事。

**逐单明细：**

- **R12 SSH 会话保活**
  - 问题：`ssh.rs` 无 keepalive（G1 核实），空闲会话被 NAT/防火墙掐断且无预警，用户以为产品坏了。
  - 整改：`ssh_dial` 拨号层启用 russh keepalive（interval 30s、连续 3 次无响应判断线）；默认全局开启，不做配置项（动线收敛原则）；断线后走既有 `sshError` 人话文案。
  - 验收：① 本地起 sshd 空闲 >10 分钟会话存活；② 拔网线场景 90 秒内出断线文案；③ verify.sh 全过。
  - 范围：dou-app `src-tauri/src/ssh.rs` 单点。
- **R13 复制粘贴 + 右键菜单**
  - 问题：终端无右键菜单、无选中复制（G2 核实）；Ctrl+V 在 xterm 里是字面 `^V`，系统剪贴板粘贴缺失。
  - 整改：`attachCustomKeyEventHandler` 接管 Ctrl+Shift+C/V 与「有选区时 Ctrl+C=复制」；右键菜单四项（复制/粘贴/全选/清屏），菜单条目文案与整体设计 token 一致。
  - 验收：真窗口右键截图 + 选中复制/粘贴往返验证。
  - 范围：dou-app `components/TerminalPanel.vue`、`core/useTerminal.ts`。
- **R14 终端内查找**
  - 问题：未装 search addon（G3 核实），翻日志只能肉眼滚屏。
  - 整改：引入 `@xterm/addon-search` + `@xterm/addon-search-bar`（或自绘查找条，与设计 token 一致）；Ctrl+F 唤起，高亮命中、上下跳转、大小写开关、Esc 关闭。
  - 验收：真窗口查找命中高亮截图；与 R13 的 Ctrl 键接管不冲突（同一 handler 内分流）。
  - 范围：dou-app `TerminalPanel.vue`、`package.json`。
- **R15 标签键盘动线**
  - 问题：`switchTab` 仅点击绑定（G4 核实），多标签效率低。
  - 整改：Ctrl+Tab / Ctrl+Shift+Tab 循环切换、Ctrl+1..9 直达、Ctrl+W 关闭当前（复用 closeTab 既有确认语义）；快捷键经 R13 的 customKeyEventHandler 放行，不污染终端输入。
  - 验收：真窗口按键验证（≥3 标签循环、直达、关闭）。
  - 范围：dou-app `TerminalPanel.vue`、`core/useTerminal.ts`。
- **R16 档案列表过滤**
  - 问题：档案 >10 台不可导航（G5 核实）；PuTTY 因无分组被竞品对比点名（反面教材）。
  - 整改：列表顶部实时过滤框（匹配名称/host/user），空结果给空态文案；分组/标签不做（小步，数据结构不动）。
  - 验收：过滤命中/空态截图；旧保险库（无新字段）兼容解锁。
  - 范围：dou-app `ConnectionsPanel.vue`（前端 only）。
