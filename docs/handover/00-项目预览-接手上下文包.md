## 0. 一句话结论

`E:/思考/dou` 里实际存在**两套互不相连的 Rust 工程**：一套是功能相当完整、可运行的本地回环 MCP 网关 `crates/dou-gateway`（axum + russh + rusqlite），另一套是 `app/src-tauri` 的**官方 Tauri + Vue 模板**（只有一个 `greet` 命令）。`docs/` 中大量文档描述的功能完整桌面客户端（多标签终端、SFTP 树、monaco、审批卡片、接入向导、1320×1000 窗口、网关自启等）**不在当前工作区的 `app/` 源码里**。这是接手时的头号陷阱：若按 `PLAN-V2.md` 的「已达成基线」继续排期，会凭空少算数十人天。

额外前提：**该目录不是 git 仓库**（无 `.git`），`docs/spike-report-006.md:17-19` 提到编译副本在 `E:\dou-app\`（仓库外），因此源码与可运行产物可能分离，无法追溯提交历史。

`Cargo.toml` 明确 `exclude = ["app/src-tauri"]`；`app/src-tauri` 有独立 `Cargo.lock`。三条可能通道逐一核验：

| 通道 | 现状 |
|---|---|

### 2.2 状态与并发模型

`main.rs:38-50` 的 `AppState` 挂 5 个共享容器：`token`、`audit`（路径）、`dev`、`sessions: Mutex<HashMap<String, SshConnection>>`、`taskhub`、`sanitizer`、`quota: Mutex<HashMap>`、`leases: Mutex<HashMap>`。**配额、租约、任务、会话全为内存态，进程重启即丢**；`store.rs` 的 `session` 表未接入。

### 2.3 HTTP 路由与鉴权状况（`main.rs:162-176`）

```
POST /mcp                 MCP JSON-RPC（initialize / ping / tools/list / tools/call；通知 202）  ← 唯一走 Bearer 校验
GET  /health              "ok"                                              无鉴权
GET  /audit               最近 50 条                                         无鉴权
GET  /audit/query          since_ms & source & limit                          无鉴权
GET  /audit/verify         链式哈希校验                                        无鉴权
GET  /audit/export         CSV 导出                                           无鉴权
GET  /tasks                任务列表                                            无鉴权
POST /approve              批准/拒绝待审任务                                    无鉴权
GET|POST /scope/tokens     列出 / 签发设备令牌                                   无鉴权
POST /scope/revoke         吊销凭据                                            无鉴权
GET  /onboard/config       生成 6 类客户端配置片段                                无鉴权
```

`Router` 上**没有任何 middleware / layer**。任何本机进程都能读审计、签凭据、批准危险命令、代写客户端配置。这是最高优先级安全缺口。

| 用途 | 命令 | 出处 |
|---|---|---|
| 网关构建 | `.\scripts\build.ps1 build` / `build --release` / `run` / `test` | `README.md:44`、`scripts/build.ps1` |

| 前端 | `npm run dev` / `npm run build`（`vue-tsc --noEmit && vite build`） / `npm run tauri dev|build` | `app/package.json` |
| 自检 | `python tools/mcp_probe.py`（9 项，含端口/握手/五工具/三档/401/审计）、`probe_ssh.py`、`probe_sftp.py`、`probe_approve.py`、`benchmark.py --runs 30` | `README.md:101`、`docs/GAP-REPORT.md:144-145` |
| WSL 靶机 | `wsl -d Ubuntu-22.04 -u root --exec sh -c "systemctl start ssh; sleep 3600"`（不能省 sleep） | `README.md:79` |

**本机硬约束（换机器必改）**：
1. `.cargo/config.toml` 把 `target-dir` 指到 ASCII 路径 `E:/dou-target`（中文路径会让 MinGW `dlltool` 乱码），linker/ar 为用户级 WinLibs **绝对路径**。
2. 无 MSVC 链接器 / 无管理员权限 → 网关走 MinGW GNU；`scripts/build.ps1` 注入 `dlltool` PATH 并**强制 `Stop-Process dou-gateway`**（否则 `os error 5`）。
3. `russh` 必须 `ring` 后端，不能用 `aws-lc-rs`（需 CMake+MSVC）。
4. Tauri 壳在 GNU 下 `ld.exe: export ordinal too large: 92875`，文档称需切 MSVC —— 与 `README.md:27`「本机没有 MSVC」矛盾。
5. `run_local` 走 `cmd /C`，Windows 下 Unix 命令会失败或 GBK 乱码。
6. `scan.rs:to_wsl_path` 写死 `C:`/`E:` 盘符与 `Ubuntu-22.04`；`build.ps1` 写死 WinGet 包路径。

## 7. 现状缺口清单（供 PM / 架构师 / QA 各自取用）

**安全（P0）**：REST 全端点无鉴权；dev 默认开；令牌/配对码非 CSPRNG；`scope.rs::hash_token` 非密码学哈希；`scan.rs` WSL 分支退出码非 1 时可能 fail-open；`check_remote_path` 用字符串 `contains`（`/home/*/.ssh/id_` 的 `*` 是字面量），未防 `../` 与符号链接；`BLOCK_PATTERNS` 无参数级结构解析；`dou.exec` 不做路径校验。

**功能/一致性**：`dou.put` 工具描述称「先落隔离区审查」，实现直接写远端；提示文案引用不存在的 `dou.task_status` 工具；`dou.exec` 的 `inputSchema` 未声明 `background` 却读取该参数；`not_implemented()` 死代码；`store.rs` 的 `list_rules/upsert_rule/...` 无调用点，`seed_builtin_rules` 写入 DB 但 `policy.rs::classify` 用硬编码常量 →「策略可配置」未落地；`upsert_snapshot` 裸 INSERT 导致同命令主键冲突被静默吞掉；`default_scope.hosts` 为空但无按 host 校验调用点；配对码与租约无 HTTP/MCP 入口。

**工程质量**：16 个 `.rs` 扁平无 `lib.rs` / 无分层；`AppState` 单结构体挂 5 个共享容器；配额/租约/任务/会话全内存态重启即丢；审计 JSONL 与 SQLite 双写分散；大量 `unwrap()` / `let _ =` 静默吞错 + `panic = "abort"`；硬编码本机路径与盘符；两套 Rust 工程无桥接。

**测试**：7 个单测；无前端单测 / e2e / 集成测试 / CI / 覆盖率；`tools/*.py` 是手工探测脚本而非测试框架。

**文档**：README 目录树与状态表滞后且自相矛盾；`GAP-REPORT` / `PLAN-V2` / `TEST-REPORT` 把历史态当基线；`ADR-001`「暂不引入 Tauri 外壳」与 `app/` 存在 Tauri 工程需调和。
