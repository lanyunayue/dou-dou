## 2. 本轮实测基线与环境（只读复核，2026-11-12）

| # | 项 | 实测数值 | 与上游一致性 |
|---|---|---|---|
| E-1 | TCP `127.0.0.1:7419` | **CLOSED/FREE**（网关未运行） | 与 `08 M-10` 一致 → 本轮脚本基线 = `NOT RUNNING` |
| E-2 | TCP `127.0.0.1:22` | **CLOSED**（SSH 靶机不可用） | 与 `07 F-08` / `08 M-07` 一致 → `RESTRICTED` |
| E-3 | `%LOCALAPPDATA%/dou/token.txt` | **EXISTS**（内容绝不打印） | 与 `07 §3` 一致；脚本运行时注入成功、len=31 |
| E-4 | Python | **3.13.14** | 可运行 `tools/*.py` |
| E-5 | `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY` | **`http://127.0.0.1:52668`** | **本轮新发现**（见下） |
| E-6 | `git status --porcelain` | `05` 被修改 + `07`/`08`/`08-bridge-dataflow.mermaid` 未跟踪 | 均为**前序/他人文档产物**，非 `crates/dou-gateway`、非本轮改动 |
| E-7 | `git diff -- crates/dou-gateway/` | **空** | 网关侧本轮零改动（V9） |

> **本轮关键发现（E-5）**：环境设了本机 HTTP 代理 `127.0.0.1:52668`。`urllib.request.urlopen` 会把 `http://127.0.0.1:7419/*` 转发给该代理；网关未运行时代理返回 **502 `upstream connect failed ... os error 10061`**，而非真正的网络异常。若脚本不处理，会把「网关未运行」误判成 22 条断言里的 10 条 FAIL（`12/22 passed`、exit 1）——**既非 `NOT RUNNING`、也违反「不误判失败」**。
> **处置**：`test_dou_e2e.py` 用 `urllib.request.build_opener(ProxyHandler({}))` **直连回环、绕过系统代理**。修复后网关 down → 真正网络异常 → 正确进入 `NOT RUNNING`（exit 2）。登记为用例 **TC-B-10**。

## 4. 验证资产：`tools/test_dou_e2e.py`

| 维度 | 实现 |
|---|---|
| **令牌运行时注入** | `DOU_TOKEN` 环境变量优先 → 否则 `%LOCALAPPDATA%/dou/token.txt`，回退链 `LOCALAPPDATA → USERPROFILE → HOME → "."` 再 `.join("dou").join("token.txt")`（与 `auth.rs:14-20` 逐字一致）。**绝不硬编码**；值仅存局部变量，不打印、不落盘、不进 URL/body |
| **输出脱敏** | 所有响应体片段先经 `redact()`：替换主令牌 + 正则 `dou_ak_[0-9A-Za-z]+` → `[REDACTED]`。`POST /scope/tokens` 合法签发的新设备凭据也不会被打印 |
| **GET（6）** | `/onboard/config?client=workbuddy`、`/audit/query?source=agent&limit=30`、`/tasks`、`/scope/tokens`、`/console`、`/audit/export` |
| **POST（3，空 body `{}`）** | `/approve`、`/scope/tokens`、`/scope/revoke`。允许 400/500，**禁止 401/403/429** |
| **逐条 PASS/FAIL 断言** | ① `/health` 无鉴权 200 + 精确 `{"status":"ok"}`；② 每端点状态码（GET=200 / POST∉401,403,429）；③ 每端点响应体不含主令牌字面量；④ `/tasks` 读到待审任务并输出 `count`；⑤ `/onboard/config` 不含完整主令牌 + `${DOU_TOKEN}` 占位符保留 |
| **22 端口** | 不可用打印 `RESTRICTED: SSH target unavailable`，**不进 N/M、不判失败也不判通过** |
| **汇总** | `result: N/M passed`；退出码 **0**=全绿 / **1**=有 FAIL / **2**=`NOT RUNNING`（网关未运行或令牌缺失，第三态：既不伪造通过也不误判失败） |
| **优雅离线降级** | 网关不可达 → 直接 `NOT RUNNING`，HTTP 断言不执行、不崩溃、不伪造；不自行启动网关 |
| **代理绕过** | `ProxyHandler({})` 直连回环（见 §2 E-5） |

> **已知、如实登记的副作用**：`POST /scope/tokens` 空 body 会按网关默认签发一条 `observe` 设备凭据（`main.rs:362-375`），属设计内行为、非主令牌回吐，可被 `/scope/revoke` 清理并写审计；脚本不打印该凭据。
