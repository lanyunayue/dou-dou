## 零、执行约定

**我不再找你确认的事**：技术选型、模块划分、接口形状、测试用例设计、代码风格、重构、依赖升级、构建脚本调整、文档措辞。

**只有这六种情况我会停**（其余一律自主推进）：

1. 需要你的账号 / 授权（真实服务器凭据、代码签名证书、应用商店账号）
2. 需要花钱（云主机、证书、分发渠道）
3. 需要你在提权终端里手动操作（安装 MSVC、改系统级配置）
4. 发现需求本身矛盾，两种解法代价差 3 倍以上且不可回退
5. 触到法律/合规红线（数据出境、隐私政策、商用许可）
6. 你主动叫停

**当前默认假设（你可一句话推翻，不推翻我就按这个做）**：

| 项 | 默认假设 | 若你要改 |
|---|---|---|
| 靶机 | 一直用 WSL 自建 sshd，不申请真实服务器 | 给我一台可连的主机 + 账号 |
| 平台 | Windows 单平台 | 加 macOS/Linux 则工期 ×1.8 |
| 计划书正文 | 暂不修订，只在 docs 里记录冲突 | 要改则单独一轮做 |
| 终端形态 | 只做托盘 + 接入面，不做自有终端渲染 | 要自有终端则 P3 工期 ×3 |
| 病毒扫描 | 先不做 ClamAV，用哈希 + 隔离区替代 | 要离线扫描引擎则增加 8 人天并突破 30MB 约束 |
