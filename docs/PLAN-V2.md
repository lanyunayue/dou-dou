> 版本：R2 · 2026-11-11
> 基线：对照《豆项目计划书_第五版_投资版》逐条复核，缺口明细见 `GAP-REPORT.md` 第八节。

## 一、现状基线

### 1.1 已达成（✅，编译/接口已验证）

- **P0 终端与会话**：多会话标签、SFTP 列目录/过滤/上级跳转、递归传输与断点续传、编辑器懒加载与 mtime 比对、Canvas/WebGL 双渲染、关窗隐藏 + tmux 接管、失焦通知与角标、导出净化、分组广播、MobaXterm 导入。
- **网关审查**：SQLite 六表、三段指纹、上下文采集、四类处置、6 类脱敏正则 + 追加规则、审计时间/来源检索。
- **凭据与作用域**：配对码 60s 一次性、设备令牌哈希落库/吊销、30min 会话租约、七维作用域、调用点强制校验（实测 observe 越权 exec 被拒、白名单放行、吊销 401）。
- **接入向导**：六类客户端片段生成、JSON 代写三约束（备份/校验/回滚/回报）、TOML 降级复制、握手自检。
- **审批**：三按钮、拒绝理由必填入审计、变更档不可关闭审批。
- **本轮回归**：前端 `vue-tsc + vite build`、网关 GNU、壳子 MSVC 三方编译通过；11 个 HTTP 端点 200；鉴权闭环与审计链校验通过；窗口默认 1320×1000。

### 1.2 基线判断

骨架与主链路已贯通，但距离计划书 M3「代理可完成一次完整执行→下载→审查→留痕闭环」和 M4「可发布 Beta」之间，还差**闭环补齐、安全加固、前端形态、质量门禁、打包实测**五类工作。当前主要风险不在「能不能写出来」，而在**真实靶机环境未验证**与**工程质量门禁（测试/分层/四态）尚未建立**。
